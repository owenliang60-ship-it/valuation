# 063 — Dollar Volume 残缺快照被当作成功发布

Date: 2026-09-07
Status: implemented and verified on codex/dollar-volume-integrity; NOT deployed.

## 事实与归因

9/4早上FMP补充查询仅82行，候选574，最终排名95条，collector仍记录ok并发布。返回数量变化有日志证据，但未取得上游原始响应和服务端解释，不能断言FMP内部故障原因。客户端缺少完整性门控是已确认缺陷。

只读导出的全历史数量审计还发现数据库日期标签2026-07-15=119、07-30=99、08-14=89条。09-04原95条已被issue062的日期修复替换为真正09-04交易日200条；不得把旧95条恢复覆盖回去。上述老标签不保证等于美股交易日，issue062之前存在采集日期错标。

## 修复

- 新采集：候选至少max(800, 最近20个完整成功日扫描量中位数×80%)；当前云端快照门槛804。上一可验证采集日Top20至少80%仍有有效量价（允许名次改变）。
- 排名必须200条、排名连续、代码唯一、价格/量/额有限且正数、成交额降序。删除股息/均线冒充价格fallback。
- 不通过时最多重采一次；仍失败返回unavailable、排名及新面孔为空，CLI退出1。上游请求异常使用固定脱敏原因。
- 不覆盖已有缓存和采集日志；无快照的新日期写失败采集状态但不写排名，保证历史查询能看见失败日。
- 缓存重新检查200条和采集覆盖证据，不再“有一行就跳过”。
- 前次采集失败则变化显示“—”，不回退更早日期制造NEW；30日历史不足或含坏日则新面孔暂停。HTML红色告警，PNG/PDF红色告警，文本显式状态；其他晨报区块继续正常发送。
